# WPiko Chatbot Pro

WPiko Chatbot Pro adds advanced features to [WPiko AI Chatbot](https://wordpress.org/plugins/wpiko-chatbot/), including live chat, a mobile agent app, analytics, lead capture, and WooCommerce integration.

## Features

- **Live chat:** take over conversations from WordPress or the mobile app.
- **Mobile app (PWA):** monitor conversations, reply to visitors, and receive push notifications.
- **Analytics:** explore conversation activity and visitor interactions.
- **Lead capture:** collect email addresses and contact-form submissions.
- **Website training:** scan content and manage questions and answers.
- **WooCommerce integration:** display product cards and provide shopping assistance.

## Requirements

- WordPress 6.0 or newer.
- PHP 7.0 or newer, as declared in the plugin header.
- WPiko Chatbot 2.0.7 or newer, installed and active.
- A valid WPiko license to enable premium features.
- An OpenAI API key for AI features; WooCommerce for shopping features.

Updates are delivered through WordPress using published GitHub Releases. The updater caches release checks for 12 hours; administrators can use **Force Update Check** on the License Activation page.
